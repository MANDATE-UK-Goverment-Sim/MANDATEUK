MANDATE — Government Simulator (Westminster Analyst UI)

FILES ARE FLAT / ROOT-LEVEL ONLY:
- index.html
- styles.css
- app.js
- mandate-logo.svg
- uk-map.svg
- README.txt

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in a browser, or upload all files to the root of your GitHub Pages repository.
3. No folders are required.

FEATURES INCLUDED
- Full Westminster Analyst-style UI rebuild
- Working light/dark mode, saved locally
- Dashboard with political map, cabinet, legislation, events, public opinion and election night
- Week-by-week simulation engine
- Random events: resignations, rebellions, leaks, by-elections, economic shocks and crises
- PM approval, trust, political capital and party unity
- Cabinet loyalty + working reshuffle action
- Parliament and government seat arithmetic
- Confidence vote, PMQs, rebellions and by-election actions
- Draft legislation flow
- Economy simulation
- Public opinion and polling
- Media actions and press conference
- Intelligence/risk screen
- 25-week election campaign countdown
- Election night exit poll
- Progressive constituency declarations
- Election speed controls and Finish Election
- Result writes back to Parliament seats/history
- Local save state using browser localStorage

NOTES
- The UK map is a stylised vector asset designed for the simulator, not an official constituency boundary file.
- All minister names are fictional.
